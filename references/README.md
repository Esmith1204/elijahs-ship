# References

Visual references for Elijah's Ship. Nothing in this folder ships with the site.

## Images

- `ref-01-character-poster.png`: saturated blue, yellow accent blocks, vertical type, crosshair, sparkle, framed border with corner labels.
- `ref-02-future-of-sky.png`: sky blue, halftone dots, wide techno type, a grey "control panel" strip of UI fragments and tick marks.
- `ref-03-rider-poster.png`: blue gradient, thin white guide lines, light lowercase display type, small stat blocks.

What they share, and what the site borrows: thin guide lines, small technical labels, blue as the loud color, and type set at two extremes (very large and very small).
